MovieLens 100K Recommendation System
    An end-to-end deep learning collaborative filtering pipeline built with TensorFlow/Keras using user and movie embeddings with dropout layers to predict 1–5 star movie ratings
   1) Dataset: MovieLens 100K
   2) Model Architecture: Neural Collaborative Filtering (NCF) with Embedding & Dense layers
   3) Metrics: Evaluated on MSE, MAE, and RMSE
